# Formato: [age]_[gender]_[race]_[datetime].jpg  (UTKFace)
# race: 0=White, 1=Black, 2=Asian, 3=Indian, 4=Others
UTKFace Aligned & Cropped: https://drive.google.com/drive/folders/0BxYys69jI14kU0I1YUQyY1ZDRUE?usp=sharing (ZIP ~107 MB)
Espejo en Kaggle: busca "UTKFace" (p. ej. `jangedoo/utkface-new`).

Este repositorio no incluye las fotos por licencia (solo investigacion no comercial).
Descarga el ZIP, descomprimelo en `data/raw/UTKFace/` y ejecuta `python src/train.py --data-dir data/raw/UTKFace`.
